# Akshat Sharma — Portfolio

A modern, animated single-page portfolio built with plain HTML, CSS and JavaScript (no build step).

- Three.js particle galaxy hero (loaded from cdnjs)
- Scroll-reveal animations, counters, typing effect, card tilt
- Placeholder images from picsum.photos
- Palette: `#7C5CFF` `#22D3EE` `#F472B6` on `#0B1020`

## Run locally
Open `index.html` in a browser, or serve the folder with any static server.

## Deploy
Deployed on Render as a static site (publish directory: `.`, no build command).
